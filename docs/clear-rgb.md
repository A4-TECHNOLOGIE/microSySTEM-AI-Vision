# turn off the RGB LEDs

Turns off RGB0 and RGB1.

```sig
a4MicroSystemAiVision.clearRgb()
```

## Example

```blocks
input.onButtonPressed(Button.A, function () {
    a4MicroSystemAiVision.clearRgb()
})
```
