# battery level (%)

Returns the battery level reported by the DFR1216 controller as a percentage.

```sig
a4MicroSystemAiVision.batteryLevel()
```

## Example

This program displays the battery level on the micro:bit LED matrix.

```blocks
basic.showNumber(a4MicroSystemAiVision.batteryLevel())
```
